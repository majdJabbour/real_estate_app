# Original Figma icon inventory

Phase 4.1 measured the supplied Original Blue frames and checked icon geometry in the theme variants. A slot is the instance or wrapper size. Vector bounds below are the distinct visible layer dimensions measured inside the slot. Mask and boolean child bounds may contribute more than one value. Fills are the blue-frame authored paints, so black mask layers can appear alongside the visible ink. Outline and filled states are listed where the source defines them. App assets and licenses are listed separately. [Asset provenance](ASSET_LICENSES.md)
